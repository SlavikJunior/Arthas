Домашнее задание №4 - Coroutines
Дедлайн: 01.12 - 100%, 08.12 - 50%

Обязательная часть:
Реализовать приложение со следующим экраном

Основной экран:

- На экране есть Slider (https://developer.android.com/develop/ui/compose/components/slider),
который отвечает за количество запускаемых корутин. Изменяется в диапазоне от 10 до 100  с шагом в 5

- Dropdown. Выбираете пул диспатчеров, на которых запускаются корутины. По умолчанию - Dispatchers.Default

- Switch. Отвечает за то, будут ли корутины запущены последовательно
- Switch. Отвечает за то, будут ли корутины запущены параллельно
По умолчанию включен свич последовательного запуска.
Если пользователь выбирает свич параллельного запуска -
свич последовательного запуска должен выключаться, свич параллельного - включаться.
Если пользователь выключает один из свичей - второй включается.

- Switch. Если выключен - корутины запускаются в момент создания. Если включен - корутины запускаются отложенно

- Кнопка. По нажатию на кнопку - запускаете корутины с выбранными настройками.
Пока происходит выполнение корутин, скрываете кнопку запуска, показываете Loading / Progress Bar.
Когда все корутины завершаются, скрываете Progress Bar, снова показываете кнопку запуска.

Теперь про сами корутины. Каждая корутина эмулирует "тяжелую" операцию.
В рамках этого задания внутри корутины делается delay на случайное время. Минимум - 1 секунда, максимум - 10 секунд.
// Будет что-то в духе
val job = launch(selectedDispatcher) {
     val delayTime = // логика получения случайного значения
     delay(delayTime)
     ...
     // additionalLogic
}
Если выполнение корутины заняло 7 и более секунд - с 30% шансом нужно выбрасывать
один из трех случайных Exception-ов. В зависимости от того,
какой Exception был выброшен - показывать Toast,
Snackbar (https://developer.android.com/develop/ui/compose/components/snackbar)
или сбрасывать все настройки корутин по умолчанию.
Какому Exception-у какое поведение будет соответствовать - выбор за вами.
Можете использовать готовые экзепшены, либо создать свои

Опциональная часть:

1. Реализовать кнопку отмены запущенных корутин.
Когда происходит запуск корутин и кнопка скрывается,
на ее месте показываете новую кнопку (либо меняете текст и логику нажатия на кнопке запуска),
логика Progress Bar-а остается без изменений. По нажатию на кнопку - нужно отменить все корутины,
которые не успели завершиться на момент нажатия кнопки остановки.
Показать Toast с количеством корутин, которое было отменено,
скрыть кнопку остановки, скрыть Progress Bar, снова показать кнопку запуска

2. Добавить Switch с названием "Работа в бэкграунде. Если свич включен  - корутины работают как обычно,
т.е. продолжают выполнение, когда приложение свернуто, никак не реагируют на разворачивание.
Если свич выключен - при сворачивании приложения автоматически завершать все незавершенные корутины.
Когда приложение разворачивается - заново запускать такое количество корутин, которое было остановлено

Если делали опциональное задание - выставить 100 корутин, выставить паралелльный запуск, запустить.
