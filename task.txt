Домашнее задание №3 - Notifications
Дедлайн: 07.11 - 100%, 14.11 - 50%

Обязательная часть
Реализовать приложение со следующей логикой

Навигация между экранами через BottomNavigation с 3-мя вкладками

Экран с настройками уведомления

- На экране есть 2 поля для ввода текста. В первое поле вводится заголовок уведомления,
если поле пустое - показывать ошибку. Во второе поле вводится текст уведомления, опциональное поле.

- Switch. Если текст достаточно длинный и целиком не вмещается в окно уведомления,
этот свич контроллирует, будет ли уведомление раскрываться
(выключенный - не раскрывается, включенный - раскрывается).
Если во втором текстовом поле нет текста, свич становится неактивным и выключается, даже если он включен

- Dropdown, в котором выбирается приоритет уведомления. По умолчанию используется Importance.Medium.
Выбор между 4-мя приоритетами уведомлений. Вы должны обеспечить обратную совместимость
с 7-ой версией андроида (даже если у вас minSdk = 26)

- Switch. Если включен, то при нажатии на уведомление должна открываться MainActivity
c Intent-ом, в котором передается заголовок и текст уведомления.
Если выключен, при нажатии на ваше уведомление ничего не происходит

- Switch. Добавляет кнопку, по нажатию на которую в окне уведомления появляется
текстовое поле (Reply action). Пользователь может ввести ответ и нажать на кнопку.
По нажатию на кнопку, вы должны запустить Broadcast Receiver, принять ответ пользователя,
сохранить его и отобразить на экране сообщений пользователя.
Если таким образом было отправлено несколько уведомлений, отображайте их в хронологическом порядке.
После успешного сохранения текста, уведомление нужно закрыть

- Кнопка. По нажатию на кнопку создавать уведомление с заданными настройками

Экран редактирования уведомления:

На экране 2 поля для ввода текста.
В первое вводится айдишник уведомления, во второе поле - текст уведомления.
По нажатию на кнопку - нужно обновить текст уведомления, если оно существует.
Если уведомления с таким айдишником в данный момент нет - показать Toast сообщение с ошибкой

По нажатию на вторую кнопку - смахнуть все уведомления из центра уведомлений,
или высветить Toast сообщение, если уведомлений нет

Экран сообщений пользователя

Есть поле для ввода текста, lazyColumn и кнопка. В поле вводится текст сообщения.
По нажатию на кнопку - текст добавляется в lazyColumn и отображается в общем списке,
поле ввода текста становится пустым.
Также в lazyColumn добавляется текст, который приходит из уведомления через ReplyAction
Сообщения должны сохраняться в рамках одной сессии при навигации между экранами

Что должно быть на скринкасте:
1) Открываете первый экран - вбиваете любой заголовок и
текст уведомления - выбираете средний приоритет - отправляете уведомление - открываете
центр уведомлений и показываете отправленное уведомление  - открываете второй экран - вводите айдишник
отправленного уведомления - вводите новый текст уведомления - жмете на кнопку,
показываете уведомление с новым текстом, смахиваете уведомление.
Снова жмете на кнопку обновления текста - показываете ошибку
2) Открываете третий экран - добавляете 2 сообщения  - открываете первый экран - создаете уведомление
с Reply Action-ом - выставляете максимальный приоритет - показываете
уведомление - вводите любой текст в текстовом поле внутри уведомления - отправляете сообщение - вновь
показываете третий экран, в lazyColumn которого было добавлено введенное ранее сообщение
