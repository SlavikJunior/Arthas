Домашнее задание №2 - Compose & Navigation
Дедлайн: 30.10 - 100%, 06.11 - 50%

Обязательная часть
Реализовать приложение со следующей логикой.

Первый экран:
На экране есть два поля для ввода текста и кнопка.
В первый textField вводится адрес электронной почты, во второй textField
вводится пароль. Кнопка привязывается к нижней части экрана с
небольшим отступом снизу (но не залезает под navbar). По нажатию на кнопку - переходим на второй экран
Какие есть требования:
- По нажатию на кнопку проверять корректность данных в текстовых полях.
Если в первом и/или втором поле нет текста - показывать соответствующее сообщение.
Если строка в первом поле не соответствует маске адреса электронной почты -
показывать соответствующее сообщение.
- Во втором текстовом поле должна быть дополнительная кнопка, которая показывает/скрывает
вводимый пароль. По умолчанию пароль должен быть скрыт. Минимальная длина пароля - 8 символов.
- Если после показа ошибки, пользователь начинает изменение текста -
сбрасывать состояние ошибки для этого конкретного поля
- Переводить пользователя на второй экран только в том случае, если выполнены все перечисленные условия

Второй экран:
На экране есть поле для отображения текста, LazyColumn и кнопка.
В текстовом поле  нужно показывать адрес электронной почты, введенный на предыдущем экране
По нажатию на кнопку - открывать третий экран
В lazyColumn отображаете список заметок пользователя. По умолчанию он пустой

Третий экран
Здесь есть два поля для ввода текста и кнопка. В первое поле вводится заголовок заметки (не может быть пустым),
во второе поле вводится текст заметки (может быть пустым).
По нажатию на кнопку "Сохранить" - проверять, что заголовок заметки не пустой,
и возвращать пользователя на предыдущий экран. Обновлять lazyColumn и добавить в него новую заметку.

ВАЖНО: вам не нужно реализовывать механизмы сохранение аккаунта пользователя и списка его заметок.
Достаточно, чтобы все работало в рамках одного запуска приложения

Опциональная часть:
1) На первом экране, когда появляется клавиатура, реализовать поднятие кнопки над клавиатурой.
Как это выглядит - кнопка привязана к низу экрана - пользователь жмет на текстовое поле -
появляется клавиатура - кнопка поднимается вместе с клавиатурой

2) Добавить на второй экран Dropdown список с цветовой схемой (минимум 3 цвета).
По нажатию на список - показывать все цвета. После выбора конкретного цвета - менять цветовую схему на всех экранах.
Пример: в списке есть 3 цвета: красный, зеленый, синий -
пользователь выбирает красный - у вас на всех экранах меняется цвет бэкграунда и
кнопок на красный (т.е. сам основной цвет бэкграуда может быть бледно красным, а кнопки уже более насыщенные)

Ограничения:
- Запрещено использование сторонних библиотек, все реализуется основными средствами андроида и Jetpack библиотеками
